## 1. Цель работы
Изучить разветвляющиеся структуры и работу условного оператора (`if...else`). Построить блок-схему вычисления значения составной функции, имеющей различный вид на разных участках аргумента, и реализовать данный алгоритм программно на языках C и C++.

## 2. Постановка задачи (Вариант 10)

Вычислить значение функции:

$$y = \begin{cases} 
e^{-(x+8)}, & x > 3.61 \\ 
1, & 0 \le x \le 3.61 \\ 
\frac{x}{5}, & x < 0 
\end{cases}$$

Значение аргумента $x$ вводится пользователем с клавиатуры.

---

```mermaid
flowchart TD

    Input --> Cond1{"x > 3.61 ?"}

    Cond2 -- Да --> Branch2["y = 1"]
    Cond2 -- Нет --> Branch3["y = x / 5"]
    
    Branch1 --> Output[/Вывод y/]
    Branch2 --> Output

    Output --> End([Конец])
