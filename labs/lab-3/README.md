## 2. Постановка задачи (Вариант 9)

Написать программу, которая по введённому номеру времени года:
* `1` — зима
* `2` — весна
* `3` — лето
* `4` — осень

выводит:
1. Соответствующие месяцы.
2. Количество дней в каждом месяце.

Если введено число вне диапазона `1–4`, программа должна вывести сообщение об ошибке.

---
