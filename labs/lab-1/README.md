## Цель работы

## Задание

Определить центробежную силу Земли:

$$F = \frac{mv^2}{r}$$

где:
* $m$ — масса Земли (кг),
* $v$ — средняя скорость движения по орбите (м/с),
* $r$ — среднее расстояние до Солнца (м).

## Структура проекта

В папке `src/` представлены две реализации алгоритма:
* **`src/main.cpp`** — реализация программы на языке C++ с использованием потоков ввода-вывода `<iostream>`.
* **`src/main.c`** — реализация программы на языке C с использованием стандартной библиотеки `<stdio.h>`.

## Сборка и запуск

**Версия на C++:**
```bash
g++ src/main.cpp -o lab1_cpp
./lab1_cpp
```

**Версия на C:**
```bash
gcc src/main.c -o lab1_c
./lab1_c
```
